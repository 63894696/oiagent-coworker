# Security Policy

## Supported versions

The current `main` branch receives security fixes.

## How to report

**Do not open a public issue for a vulnerability.**

Use the repository's **Security** tab → **Report a vulnerability**. If that is
unavailable, open an issue that only asks for a private channel, without any
technical detail.

Include:

- a description and the impact;
- steps to reproduce or a proof of concept;
- affected version and platform;
- your name or handle if you want credit.

## What to expect

| Stage | Target |
| --- | --- |
| Acknowledgement | 3 business days |
| Initial triage | 7 business days |
| Status updates | every 14 days until resolved |
| Public advisory | after a fix ships, or 90 days after the report |

## Scope

In scope: the code in this repository, credential handling, and injection
through files the software loads.

Out of scope: third-party services you connect to, and vulnerabilities in
dependencies (report those upstream; this project will pick up the fix).

## Bug bounty

There is no paid bounty program. Reporters are credited at their option.
